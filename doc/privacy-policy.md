# Privacy Policy
Effective: November 1, 2023  
Last Updated: September 23, 2026

## The information we collect
With your permission and that of your server administrator, ermiana (hereinafter referred to as "the Service") may read the content of messages you send in Discord servers in order to parse webpage previews, but the content of those messages will not be permanently stored. The Service will never store any of your Discord user data, including but not limited to your Discord user ID, avatar, and profile description. Except for the URLs and their parsing results temporarily stored as described below to avoid repeated requests, the Service does not store the messages or images you send.  

If a Discord server has never used the server settings feature, the Service will not create a record for that server. When a Discord server administrator actively uses the server settings feature provided by the Service, the Service will store that Discord server's ID (Guild ID) and related feature settings in order to identify and apply the customized settings selected by that server. The Discord server ID (Guild ID) and related settings stored by the Service are used only to provide the features selected by that server and are not used to identify, track, or create a profile of any Discord user.  

## Cached data
To avoid repeated requests to the same URL, improve the performance of the Service, and reduce unnecessary access to third-party websites, the Service uses a caching system to temporarily store parsed URLs and their parsing results. Cached data contains only the URL and the parsing result for that URL and does not store any Discord user data, including but not limited to your Discord user ID, avatar, and profile description. Except for the URLs and their parsing results temporarily stored as described above to avoid repeated requests, the Service does not store the messages or images you send.  

Cached data is used only for webpage previews and related parsing features and is not used to identify, track, or create a profile of any Discord user. Cached data is not stored permanently and will usually expire or be deleted automatically within several hours according to system settings. The actual retention period may vary depending on service operation and cache settings.  

## How we use your information and third-party services
The information accessed by the Service is used only to provide the features included in the Service. The Service will not sell, rent, or provide Discord user data to advertising services, data brokers, or other third parties whose purpose is to monetize data. To provide webpage preview and image parsing features, the Service accesses third-party websites referenced by URLs sent by users. Those third-party websites may process the relevant requests in accordance with their own terms of service and privacy policies.

## Data retention
Because the Service does not create or persistently store profiles for individual Discord users, under normal circumstances there is no individual user data available for deletion. Cached data generated to avoid repeated requests contains only URLs and their parsing results, will usually expire or be deleted automatically within several hours according to system settings, and will not be stored permanently.  

When a Discord server administrator uses the server settings feature provided by the Service, the Service will store that Discord server's ID (Guild ID) and related feature settings. When the related feature settings are canceled or restored to their default state, the Service will delete that Discord server ID (Guild ID) and the related settings record and will not continue to store that server's settings data.  

If you have any concerns regarding data stored by the Service, please send a written description of your concern, together with your real name and Discord account ID, to admin#canaria.cc (replace # with @), and we will respond as soon as possible.  

## How we protect your information
The Service will take reasonable technical and administrative measures to protect stored data against unauthorized access, modification, disclosure, or destruction.  

However, no service provided over the Internet can guarantee absolute security. The Service will continue to improve relevant security measures according to actual needs.  

## Changes to this Privacy Policy
The Service may modify this Privacy Policy due to feature adjustments, changes in data processing methods, legal requirements, changes to Discord policies, or other necessary reasons.  

When this Privacy Policy is changed, we will update the Last Updated date shown on this page.  

## Contact us
If you have any questions about this Privacy Policy or how the Service processes data, please send a written description of your question, together with your name and Discord account ID, to admin#canaria.cc (replace # with @), and we will respond as soon as possible.

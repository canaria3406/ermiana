## What you can expect from us
ermiana (hereinafter referred to as "the Service") is a Discord bot that automatically parses and displays webpage previews and images. It supports PTT, Bahamut Off-Topic, Plurk, Twitter, Pixiv, and various other websites.  

Some features of the Service may be selectively enabled, disabled, or configured by Discord server administrators.  

## Using the Service
With your permission and that of your server administrator, the Service may read the content of messages you send in Discord servers in order to parse webpage previews, but the content of those messages will not be permanently stored. The Service will never store any of your user data, including but not limited to your Discord user ID, avatar, profile description, or the messages and images you send.  

To avoid repeated requests to the same URL, improve the performance of the Service, and reduce unnecessary access to third-party websites, the Service uses a caching system to temporarily store parsed URLs and their parsing results. Cached data will usually expire or be deleted automatically within several hours according to system settings. Cached data contains only the URL and the parsing result for that URL and does not store any Discord user data, including but not limited to your Discord user ID, avatar, and profile description. Except for the URLs and their parsing results temporarily stored as described above to avoid repeated requests, the Service does not store the messages or images you send.  

If a Discord server has never used the server settings feature, the Service will not create a record for that server. When a Discord server administrator actively uses the server settings feature provided by the Service, the Service will store that Discord server's ID (Guild ID) and related feature settings in order to identify and apply the customized settings selected by that server. When the related feature settings are canceled or restored to their default state, the Service will delete that Discord server ID (Guild ID) and the related settings record.  

When a server administrator adds the Service to a server, they should carefully read and agree to these Terms of Service and fulfill the obligation to notify server members. If a server administrator does not agree to these Terms of Service, they should immediately stop using the Service and remove it from the server. When server members use the Service, they should carefully read and agree to these Terms of Service. If a server member does not agree to these Terms of Service, they should immediately stop using the Service and leave all servers containing the Service.

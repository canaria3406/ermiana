# 隱私權政策
生效日期：2023年11月1日  
更新日期：2026年9月23日  

## 蒐集的資料
ermiana(以下稱"本服務")經過您或您所屬伺服器管理員的允許，得以讀取您在 Discord 伺服器中發送的訊息內容進行網頁預覽解析，但這些訊息的任何內容都不會被永久儲存。本服務永遠不會儲存任何屬於您的 Discord 使用者資料，包括但不限於您的 Discord 使用者 ID、大頭貼及個人簡介。除下述為避免重複請求而暫時儲存的網址及其解析結果外，本服務不會儲存您所傳送的訊息和圖片。  
若 Discord 伺服器未曾使用伺服器設定功能，本服務不會建立伺服器紀錄。當 Discord 伺服器管理員主動使用本服務提供的伺服器設定功能時，本服務會儲存該 Discord 伺服器的 ID（Guild ID）及相關功能設定，以識別並套用該伺服器所選擇的客製化設定。本服務所儲存的 Discord 伺服器 ID（Guild ID）及相關設定僅用於提供該伺服器所選擇的功能，不用於識別、追蹤或建立任何 Discord 使用者資料檔案。  

## 快取資料
為避免對相同網址進行重複請求、提升本服務的效能並減少對第三方網站不必要的存取，本服務會使用快取系統暫時儲存已解析的網址及其解析結果。快取資料僅包含網址及該網址的解析結果，不會儲存任何 Discord 使用者資料，包括但不限於您的 Discord 使用者 ID、大頭貼及個人簡介。除前述為避免重複請求而暫時儲存的網址及其解析結果外，本服務不會儲存您所傳送的訊息和圖片。  
快取資料僅用於網頁預覽及相關解析功能，不用於識別、追蹤或建立任何 Discord 使用者資料檔案。快取資料不會被永久保存，通常會於數小時後依照系統設定自動失效或刪除。實際保存時間可能因服務運作及快取設定而有所不同。  

## 資料使用及第三方服務
本服務存取的資料僅用於提供本服務所包含的功能。本服務不會出售、出租或提供 Discord 使用者資料予廣告服務、資料仲介或其他以資料營利為目的之第三方。為提供網頁預覽及圖片解析功能，本服務會存取使用者所發送網址所指向的第三方網站，該第三方網站可能會依照其自己的服務條款及隱私權政策處理相關請求。

## 資料保存及刪除
由於本服務不會建立或持久儲存任何個別 Discord 使用者的資料檔案，因此一般情況下不具有可供刪除的個別使用者資料。為避免重複請求而產生的快取資料僅包含網址及其解析結果，通常會於數小時後依照系統設定自動失效或刪除，不會被永久保存。  
當 Discord 伺服器管理員使用本服務所提供的伺服器設定功能時，本服務會儲存該 Discord 伺服器的 ID（Guild ID）及相關功能設定。當相關功能設定被取消或恢復為預設狀態後，本服務會刪除該 Discord 伺服器 ID（Guild ID）及相關設定紀錄，不會繼續保存該伺服器的設定資料。  
若您對本服務所保存的資料有任何疑慮，請以書面方式將您的問題描述，附上您的真實姓名和 Discord 帳號 ID，發送至 admin#canaria.cc（將 # 替換為 @），我們將盡快為您解答。  

## 資料安全
本服務將採取合理的技術及管理措施，以避免所保存的資料遭到未經授權的存取、修改、洩漏或破壞。  
然而，任何透過網際網路提供的服務均無法保證絕對安全，本服務將依照實際需求持續改善相關安全措施。  

## 隱私權政策變更
本服務可能因功能調整、資料處理方式變更、法律要求、Discord 政策變更或其他必要原因修改本隱私權政策。  
當本隱私權政策發生變更時，我們將更新本頁所記載的更新日期。  

## 問題釋疑
若您對本隱私權政策或本服務的資料處理方式有任何疑問，請以書面方式將您的問題描述，附上您的姓名和 Discord 帳號 ID，發送至 admin#canaria.cc（將 # 替換為 @），我們將盡快為您解答。
